# SmartMarket AI - Quick start
1. Install Node.js 20 LTS (nodejs.org)
2. Open terminal in this folder: `npm install`
3. `npm start`
4. Open http://localhost:3000 (do NOT double-click index.html)
Change JWT_SECRET in .env before going live.
Deploy: Render/Railway, start command `npm start`, add a persistent disk and set DB_PATH to it.
